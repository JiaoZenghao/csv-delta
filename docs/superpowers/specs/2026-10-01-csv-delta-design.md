# CSV Delta 设计

日期：2026-10-01
状态：选题及首版范围已获用户认可，具体设计待审阅。

## 目标与约束

创建公开 GitHub 开源项目，以获得 100 个真实 star 为长期目标。用户授权自主选题，优先零运行成本、易维护的开发者工具。首个验证窗口为发布后 30 天；不承诺达到目标的时间或结果。不购买 star、不互刷、不自动向他人发送推广信息。

目标用户是需要核对数据库迁移、配置表或价格表 CSV 导出的开发者。核心问题是普通文本 diff 无法区分行重排与真实数据变化。

## 定位和竞品

一句话定位：按主键核对两份 CSV，明确指出每个字段的变化，并导出可离线查看的报告。

调研参考：
- https://github.com/simonw/csv-diff — 已有命令行按主键比较工具。
- https://github.com/aurelio-nakamura/dataloupe — 已有离线 HTML 差异报告功能。
- https://github.com/SaurabhBaranawal/csv-diff-browser — 已有浏览器比较工具。

本项目以复合主键、重复键拒绝、明确的数值容差规则和可直接打开的核对报告组成聚焦体验。上述功能组合是定位假设，不能宣称唯一或已经验证市场需求。

## 首版使用流程

1. 打开网页，点击内置示例即可体验；也可选择旧、新两份 UTF-8 CSV。
2. 选择一个或多个共同列作为主键；选择忽略列以及可选数值比较列。
3. 点击比较，查看新增、删除、修改、未变计数，按类型筛选结果。
4. 修改行逐字段显示旧值和新值，另行显示列新增、列删除。
5. 导出包含完整结果和比较设置的独立 HTML 报告，无外部资源依赖。

界面提供中英文切换。数据仅保留在当前页面内存中；刷新清除，不自动保存。

## 比较语义

- 默认逐字段字符串精确比较；空白、大小写和前导零均保留。
- 行顺序不影响结果；列按列名匹配，列重排不构成变化。
- 主键使用字段值数组的无歧义编码；任何一侧存在重复键或空主键字段时拒绝比较并提示文件与行号。
- 仅对用户明确选择的数值列应用有限非负绝对容差；双方均为有限十进制数时，差值不超过容差视为相同。否则回退字符串比较。明确提示 JavaScript 浮点比较不适用于要求精确十进制的财务核算。
- 新增、删除列单独报告；共同非忽略列参与行修改判定。不存在共同列或主键列被移除时提示错误。
- 忽略列不得包含主键。忽略设置和容差均写入导出报告。

## 数据与错误处理

支持逗号、制表符、分号分隔，由用户选择，默认逗号；支持 BOM、CRLF/LF、引号内分隔符、换行和双引号转义。

拒绝空文件、空/重复表头、未闭合引号、非法引号位置、行字段数与表头不一致。错误指出输入侧和记录位置；引号内换行使物理行号与记录号不同，界面明确采用记录号。

每个输入文件限制 10 MiB、最多 50,000 条数据记录。比较结果分页，每页 100 行，避免大表全量渲染。导出包含完整结果，生成前提示报告包含输入数据，需要用户自行选择分享对象。

## 架构

使用普通 JavaScript ES modules、HTML、CSS；不引入前端框架或运行时第三方依赖。Node 内置测试运行器负责核心测试。

- CSV parser：文本到列和记录，负责格式验证及记录上限。
- comparator：接受两个解析结果及设置，输出计数、列变化和行变化；与界面独立。
- report：使用比较结果生成独立 HTML，所有输入文本转义。
- app：文件读取、设置、语言、分页和错误展示。

所有代码、字体、样式资源随项目提供，无分析追踪脚本，无文件上传接口。GitHub Pages 提供静态演示；用户文件不发出网络请求。托管服务仍可能记录页面访问。

## 验证与验收

核心测试覆盖引号、换行、BOM、格式错误、行列重排、复合键碰撞、重复键、缺失键、列变化、忽略列、容差边界与非数字回退。

通过恶意 HTML 输入验证页面及报告不会执行输入脚本。浏览器实测示例、文件选择、设置、筛选、分页、中英文和报告导出。离线打开导出报告，验证无网络资源依赖。

首版验收：示例在打开页面后一次点击可见差异；自定义文件产生正确结果；失败输入有可理解的错误；测试通过；README 含运行方式、示例、比较语义、限制和 MIT 许可证说明。
