# CSV Delta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 发布能够按复合主键比较 CSV、导出离线 HTML 报告的公开开源工具，并建立真实反馈驱动的增长跟进。

**Architecture:** CSV 解析、比较、报告生成均为独立纯函数模块。浏览器界面读取文件并管理设置、筛选和分页；GitHub Pages 静态托管。

**Tech Stack:** JavaScript ES modules、HTML、CSS、Node.js 22+ 内置测试运行器；无运行时第三方依赖。

**Spec:** docs/superpowers/specs/2026-10-01-csv-delta-design.md

## Global Constraints

- 每个输入文件限制 10 MiB、最多 50,000 条数据记录。
- 比较结果分页，每页 100 行。
- 默认逐字段字符串精确比较；空白、大小写和前导零均保留。
- 仅显式选中的数值列采用有限非负绝对容差；保留浮点精度提示。
- 数据不上传、不持久化；报告无外部资源依赖。
- 中英文界面、英文主 README、中文 README、MIT 许可证。
- 不购买或互刷 star，不自动向他人发送推广消息。

## Review Focus

- 异步读文件或修改设置期间旧结果不得被误认为当前结果；界面使旧结果失效。
- CSV 字段包含 HTML/script 时界面与报告仅显示文本。
- 主键包含分隔符时不能发生拼接碰撞；使用数组 JSON 编码。
- 零字节、BOM-only、尾部空行输入必须给出一致结果或错误。
- 表头 __proto__/constructor 等名称作为普通列，不污染对象。

### Task 2: Comparison engine

**Files:** Create src/compare.js, tests/compare.test.js.

**Interfaces:** 消费 parseCSV 结果；`compareCSV(oldData,newData,{keys,ignore=[],numeric=[],tolerance=0}) -> {counts,columnsAdded,columnsRemoved,records,settings}`。counts 含 added/removed/changed/unchanged。record 含 type、key（数组）、old（字段值映射或 null）、new（字段值映射或 null）、changes（{column,old,new} 数组）。settings 保存完整设置。

- [x] 写测试：重排行列无变化；复合键 ['a,b','c'] 与 ['a','b,c'] 不碰撞；新增/删除/字段变化计数准确；空/重复主键、未知设置列、忽略主键、无主键均报错；新增/删除列单独列出。
- [x] 写数值测试：'1.00' 与 '1' 默认不同，选择数值列后相同；1 与 1.25 容差 0.25 相同；1 与 1.26 不同；空串/Infinity/十六进制回退字符串；负数、NaN 容差报错。
