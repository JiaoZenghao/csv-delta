How to compare two CSV files, ignoring row order and timestamps

Exports can change their row order, timestamps and number formatting without changing the underlying records. Use three synthetic examples to find meaningful changes by key, entirely in your browser.

Updated October 7, 2026 · 5 minute read

Why a line diff can be misleading

A text diff compares lines and strings. Reordering can make the same product look removed and added. Match sku + region to compare the same product in the same region. SKU alone is not unique in this example.

The workflow

  1. Download a before/after pair below and select both files in the browser tool. The home page also has a one-click price example.
  2. Select the keys, ignored columns and numeric columns specified for that case. Keep absolute tolerance at 0.
  3. Click Compare snapshots. Check counts and field changes; select All rows to see unchanged records.
  4. Export the HTML report and open it offline to inspect its settings and results.

If the counts differ

  • Check the file pair, composite keys and comma delimiter.
  • Without ignoring timestamps, more rows change. Without numeric mode, 9.99 and 9.990 differ.
  • Duplicate or empty keys cause an error. Inspect the export rather than arbitrarily removing duplicates.
  • Added and removed columns are reported separately; a new column does not automatically modify every row.
UTF-8 CSV only, up to 10 MiB and 50,000 records per file. JavaScript floating point is unsuitable for exact decimal accounting or integers beyond safe precision. Reports include original data, ignored columns and unchanged rows; choose recipients carefully.
